外国人には漢字が「魔法の文字」に見えている？ITheAustin and Arthur Show #187

But what’s funny is, / I’ll tell you, / so when I was in college, / I took the most narrow class ever.

でも面白いのは、/ 話しますけど、/ 私が大学生だったとき、/ ものすごく専門特化した授業を取ったんです。

It was a history / of the development of Chinese ideographs / across Asia.

それは歴史についての授業で、/ 中国の表意文字（漢字）が発展していった過程を、/ アジア全体にわたって扱うものでした。

Wow, / that sounds like a nerd class.

わあ、/ それはオタクっぽい授業に聞こえるね。

It was a nerd class, / but it was one of my favorite classes.

確かにオタクっぽい授業だったけど、/ 私のお気に入りの授業の一つだったよ。

But what was funny is, / so my professor, Zev Handel, / he’s married to a Chinese woman, / and he speaks fluent Chinese, / lived there for a long time.

でも面白かったのは、/ 私の教授のゼヴ・ハンデルは、/ 中国人女性と結婚していて、/ 中国語も流暢に話せるし、/ 長い間中国に住んでいたんだ。

And he was saying / how a lot of people try to see Chinese hanzi, / like the kanji has, / like this mystical kind of, / like there’s a special meaning / in each of these ideographs.

そして彼は言っていたんだ。/ 多くの人が中国の漢字を見て、/ 日本の漢字もそうだけど、/ 何か神秘的なものとして捉えていて、/ それぞれの文字の中に、/ 特別な意味があると思い込んでいる、と。

And the whole point of his class was, / yeah, bullshit, no way.

そして彼の授業の主旨は、/ 「いや、それはでたらめだ、そんなわけない」というものだった。

No, / all they were / was just phonetic sounds, / and then they attached the radicals to them, / like the ninben or whatever, / to say, / oh, this is the word that sounds…

いや、/ それらはもともと、/ ただの音を表すものだった。/ そして後から部首を付け加えて、/ 人偏（にんべん）みたいなものを使って、/ 「ああ、/ これはこういう意味の単語で、この音を持つものですよ」と示したんだ。

【解説】

**the most narrow class ever**

直訳すると「これまでで最も狭い授業」。ここでの *narrow* は「範囲が非常に限定された」「超専門的な」という意味です。

**nerd class**

「オタク向け授業」「マニアックな授業」。自虐的・冗談っぽい表現です。

**Chinese ideographs**

「中国の表意文字」。ここでは漢字を指しています。

**mystical kind of**

「神秘的なもの」「不思議な力を持つもの」というニュアンス。漢字一文字一文字に深遠な意味が隠されていると考える見方を指しています。

**bullshit, no way**

かなりくだけた否定表現で、「そんなの完全にでたらめだ」「ありえない」という意味です。

**radicals**

漢字の「部首」のこと。

**like the ninben or whatever**

「人偏とか、そういうやつね」という軽い言い方。話し手は漢字用語に詳しくないため *or whatever*（まあ何でもいいけど）を付けています。

I’ve kind of approached it / from the opposite side because, / I mean, / like I’ve been teaching here for 10 years, / so it’s not like I don’t know kanji.

私はどちらかというと、/ 逆の側からアプローチしてきたんだ。/ というのも、/ ここで10年間教えているから、/ 漢字を知らないわけじゃないんだよ。

It’s like usually / I’m teaching classes, / like my student rosters, / it’s like a 50-50 chance / it’s going to be in English.

普段は、/ 授業を教えていて、/ 学生名簿なんかを見ると、/ 英語表記で書かれているかどうかは、/ 半々くらいの確率なんだ。

So I’ve gotten really good / at just reading names.

だから私はかなり得意になったんだ。/ 人の名前を読むことに関してはね。

Yeah.

そうなんだ。

Right. / And so…

そう。/ それでね……

It’s funny because / that’s like the harder thing to do, / is reading names.

面白いよね、/ 実はそっちの方が難しいことだから。/ 人名を読むっていうのは。

Yeah.

そうなんだよ。

Yeah, / my reading’s like not bad, / it’s writing for me / that needs improvement.

うん、/ 読む力はそれほど悪くないんだけど、/ 私の場合は書く力の方が、/ 改善が必要なんだ。

But anyways, / one of the things / that I always teach in my English class is, / I always teach my students / that English words are actually really similar to kanji.

でもとにかく、/ 私が英語の授業でいつも教えることの一つは、/ 生徒たちにいつも伝えているんだ。/ 英単語は実は漢字ととてもよく似ているんだよ、と。

Recently, / in my high school class, / we…

最近、/ 高校の授業で、/ 私たちは……

【解説】

**approached it from the opposite side**

直訳は「反対側からそれに近づいた」。ここでは「漢字をゼロから学び始めたのではなく、教師として長年接してきた経験から入った」という意味です。

**student rosters**

「学生名簿」「出席簿」。生徒の名前が一覧になったものです。

**it’s a 50-50 chance**

「五分五分の確率」「半々の確率」という意味です。

**reading names**

日本語では「名前を読む」ですが、漢字の人名は特殊な読み方が多いため、外国人学習者にとっては一般的な漢字の文章を読むより難しいことがあります。そのため次の発言で「それの方が難しい」と言っています。

**my reading’s not bad**

「読む力は悪くない」「そこそこ読める」という控えめな言い方です。

**English words are actually really similar to kanji**

ここではまだ説明の途中ですが、おそらく「英単語も漢字と同じように、語源や構成要素（接頭辞・接尾辞など）を理解すると意味が推測できる」という話につながる流れです。

And so / one of the introductions to that is, / I wrote the word biography on the board.

それで、/ その話を導入する方法の一つとして、/ 私は黒板に「biography」という単語を書いたんだ。

Yeah.

うん。

And I was like, / how many of you know / what a biography is?

それで私はこう聞いたんだ。/ 「biography が何か知っている人はどれくらいいる？」と。

And this is like an advanced class, / we got study abroad students in here.

しかもこれは上級クラスで、/ 留学経験のある学生たちもいるんだ。

So it’s like / the English level is a lot higher / than a normal English class.

だから、/ 英語レベルはかなり高くて、/ 普通の英語クラスよりずっと上なんだ。

So it’s like / a lot of students are like, / oh yeah, / it’s, you know, / it’s like stories about people’s lives.

すると、/ 多くの学生が、/ 「ああ、知ってます」/ 「その、ほら、/ 人の人生についての話ですよね」みたいに答えたんだ。

And I’m like, / yeah, okay, / so look at this word.

そこで私は、/ 「そう、その通り」/ 「じゃあ、この単語を見てごらん」と言ったんだ。

Do you see / like any words inside this word?

この単語の中に、/ 何か別の単語が見えるかな？

Yeah.

うん。

And it’s like, / not really anyone understood.

でも、/ ほとんど誰も分からなかったんだ。

And then / like one person raised their hand / and was like, / bio?

すると、/ 一人の生徒が手を挙げて、/ 「えっと……」/ 「bioですか？」と言ったんだ。

Yeah.

そうそう。

【解説】

**one of the introductions to that**

直訳すると「そのことへの導入の一つ」。ここでは「その話題を説明し始めるための方法の一つ」という意味です。

**we got study abroad students in here**

口語的な表現で、「このクラスには留学経験のある学生もいるんだ」という意味です。

**it’s like ～**

会話で非常によく使われるつなぎ言葉です。「まあ」「つまり」「なんというか」といったニュアンスで、特に意味を持たない場合もあります。

**Do you see any words inside this word?**

英単語を語源やパーツに分解して考える練習です。

ここでは **biography = bio + graphy** のように、単語の中に意味を持つ要素を見つけられるかを尋ねています。

**bio**

ギリシャ語由来で「生命・人生」を意味する語根です。

例：

- biology（生物学）

- biography（伝記）

- biodegradable（生分解性の）

この後の話では、おそらく「英単語も漢字と同じように、部品（語根）から意味を推測できる」という説明につながっていきます。

Back in my day / before we had iPhones.

私が若かった頃は / まだiPhoneなんてなかった時代でした。

Actually, it was before the iPhone.

実際、iPhoneが登場する前のことです。

But I remember thinking about / how it was so mystical.

でも私は当時 / それがとても神秘的だと思っていたのを覚えています。

And actually, for me, / it would seem so cool.

それに実際、私にとっては / すごくかっこよく見えたんです。

Because in the States, / there’s this whole thing about getting Kanji tattoos.

というのもアメリカでは / 漢字のタトゥーを入れる文化というか流行があるんです。

People are like, / “I wanna get…”

みんな「〜の漢字を入れたいな」とか言うんです。

There’s so many YouTube videos on it.

その話題のYouTube動画もたくさんあります。

It’s so fun.

とても面白いですよ。

I know, but it’s funny, / because people are like,

そうなんですよね。でも面白いのは / みんなこう思っていることです。

“This is so cool, / because it’s so foreign,”

「これはすごくかっこいいよね。/ だってすごく異国的だから」

“and it seems almost like a magical thing.”

「それにまるで魔法のものみたいに見えるから」

Because actually, / you know what’s funny is…

というのも実は / 面白いことがあって……

This might be interesting to pull up, / but you know about…

ちょっと調べてみると面白いかもしれませんが / 〜って知っていますか？

Of course, / you know about runes, right?

もちろん / ルーン文字って知っていますよね？

Like Futhark runes, / like English-German runes.

例えばフサルク・ルーン文字みたいな / 英語圏やゲルマン系の古代文字です。

Oh, okay, yeah.

ああ、なるほど、知っていますよ。

【解説】

- **Back in my day**

  - 直訳は「私の時代には」。

  - 「私が若かった頃は」「昔は」という懐かしむ表現です。

- **mystical**

  - 「神秘的な」「不思議な力を感じさせる」という意味。

  - ここでは漢字が外国人にとって特別で魔法のように見える感覚を表しています。

- **there’s this whole thing about ～**

  - 直訳すると「〜に関するひとつの大きな事象がある」。

  - 実際には「〜が流行っている」「〜という文化・現象がある」という意味です。

- **pull up**

  - ここでは「検索して表示する」「調べてみる」という意味。

  - スマホやPCで情報を呼び出すイメージです。

- **Futhark runes**

  - 北欧・ゲルマン民族が使っていた古代文字体系「フサルク・ルーン文字」。

  - 話者は「西洋人が漢字を神秘的に感じる感覚は、日本人がルーン文字を見て神秘的だと感じる感覚に近い」と説明しようとしています。
