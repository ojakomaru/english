here I am with my dog Nari.

say hi to the camera scissor little nervous we’re at the dog park and we we’ll see if she will make some friends today.

**①**

here I am / with my dog Nari.

はい私はここにいます / 私の犬ナリと一緒に。

**ポイント**

- **Here I am** = さあ私はここにいます（動画・紹介でよく使う）

**②**

say hi to the camera / she’s a little nervous.

カメラに挨拶してね / 少し緊張しています。

**重要表現**

- **say hi** = 挨拶する（とてもよく使う）

- **a little nervous** = 少し緊張している

**③**

we’re at the dog park / and we’ll see / if she will make some friends today.

私たちはドッグランに来ています / そして様子を見てみます / 今日友達ができるかどうか。

**文法ポイント**

- **we’ll see if ～** = ～かどうか様子を見る （かなりよく使う表現）

**④**

There are a lot of big dogs today, / so I’m not sure / if she will cooperate. / we shall see.

今日は大きな犬がたくさんいるので / 私は分かりません / うまくやれるかどうか / 様子を見ましょう。

**重要単語**

- **cooperate** = 協力する・うまくやる

**⑤**

I think it would be best / if we moved away from the big dogs for now.

今のところは / 大きな犬から離れた方がいいと思います。

**文法ポイント（かなり重要）**

- **it would be best if ～** = ～した方がいい

**⑥**

so we’ll go to the corner over there / where there’s two benches / so we can sit down and relax.

だからあそこの角に行きます / ベンチが2つあるところに / そこで座ってリラックスできるので。

**重要表現**

- **over there** = あそこに

- **sit down and relax** = 座ってリラックスする

**⑦**

When was the last time / you sit on a park bench?

最後に / 公園のベンチに座ったのはいつですか？

**文法修正**

正しくは：

**When was the last time you sat on a park bench?**

- sit → 現在形 ❌

- sat → 過去形 ⭕

**⑧**

we are at a large old baseball field / that is converted into a dog park.

私たちは大きくて古い野球場にいます / ドッグランに改装された場所です。

**重要表現**

- **converted into ～** = ～に改装された

**⑨**

We like to come here / because there’s open space / for Nari to run.

私たちはここに来るのが好きです / なぜなら広いスペースがあるからです / ナリが走れるように。

**文法ポイント**

- **for ～ to ～** = ～が～するための

**⑩**

and she usually likes / to only be around small dogs / so if we see big dogs / we get to have our own area.

そしてナリは普通 / 小さい犬の近くにいるのが好きなので / もし大きい犬がいたら / 私たちは自分たちだけの場所を使います。

## ★今回の英語で一番大事な文法

① if を使った表現**

- we’ll see if she will make friends

- I’m not sure if she will cooperate

→ 英語では **if = ～かどうか

② 過去形ミスしやすいポイント**

❌ When was the last time you sit ⭕ When was the last time you sat
