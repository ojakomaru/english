**PV 13: Advanced English Phrasal Verbs about Studying and Learning - English Vocabulary for Speaking**

let's jump into the first one では最初の表現に入ろう。

to go over something**go over ～**

to go over something / this means that / you're going to review it**go over ～** は、/ それを復習する、

or look at it / a little bit more carefully. あるいは / もう少し注意深く確認する、という意味。

all right, / let's go over the chapter together よし、/ この章を一緒に見直そう。

to make sure / I understand it. ちゃんと理解できているか確認するために。

if you go over something / you might be doing it again 何かを **go over** するというのは、/ もう一度やることが多い。

so let's go over the chapter together だから **Let's go over the chapter together.** は、

meaning / let's really thoroughly look at it 「しっかり詳しく見直そう」

or / let's do it again / to review. あるいは「復習のためにもう一回やろう」という意味。

I'll go over the practice problems again / before the exam. 試験前に / 練習問題をもう一度見直すつもりだ。

yes, / like Cat said, そう、Cat が言ったように、

when you go over it / you're doing it / for the second or third time.**go over** するときは、/ 2回目や3回目として / やり直していることが多い。

if I'm at university, 大学生だとすると、

maybe I made some notes / during a lecture 授業中にノートを取るかもしれない。

and then a day later / I'll come back / and go over the notes again. そして翌日になって、/ そのノートを / もう一度見返す。

I'll read them again 再び読む。

so I remember them really well よく覚えられるように、

and I really absorb them. しっかり内容を吸収できるように。

I need to go over my notes / from last week's lecture. 先週の授業のノートを / 復習しないといけない。

or あるいは、

I'm going to go over the material / before the quiz. 小テストの前に / 学習内容を見直すつもりだ。

**イメージ

go over = 上をもう一度なぞる**

- ノートを見直す

- 資料を確認する

- 内容を復習する

- 計画を再確認する

という意味で非常によく使われます。

**例**

- *Let's go over the plan one more time.*

  - 計画をもう一度確認しよう。

- *Can we go over the details?*

  - 詳細を確認できますか？

- *I went over my English notes before the test.*

  - テスト前に英語のノートを復習した。

英語では **review** よりも会話で **go over** の方が自然に出てくることが多いです。

second phrasal verb / is to read up on something 2つ目の句動詞は / **read up on ～**。

read up on something**read up on ～**

so this is a special one / with two particles / or three parts これは少し特殊で、/ 3語から成る句動詞。

if you read something 普通の **read** は、

then you read a passage / or read an article 文章や記事を読んで、

and take in the information. 情報を取り入れること。

however, / native speakers like to emphasize / the studying part でもネイティブは、/ 「勉強する」という部分を強調したい時に、

by saying / read up.**read up** を使う。

and "up" in this case / sounds like / I'm increasing my knowledge. この **up** には、/ 「知識を増やす」というイメージがある。

so if I read up on something, だから **read up on ～** は、

I'm going to read it / and I'm really going to study it 読むだけでなく、

or research a specific topic / more intensely. 特定のテーマを / しっかり調べたり勉強したりすること。

for example, 例えば、

I'm reading up on / different study techniques さまざまな勉強法について / 調べている。

to improve my learning. 学習効率を上げるために。

that means / I am learning some techniques, つまり、

I'm reading them very closely それらを注意深く読んで、

and really paying attention to them. しっかり理解しようとしている。

one more example, もう一つ。

I want to read up on / the latest discoveries in Neuroscience. 神経科学の最新の発見について / 勉強したい。

I'm going to read up on / the history of the Roman Empire ローマ帝国の歴史について / 調べるつもりだ。

for my history essay. 歴史のレポートのために。

so I'm going to do that research. つまりそのテーマを調査するんだ。

right? そうでしょ？

so I'm going to read up on it. だから **read up on it** と言う。

also, / I feel like / "research" sounds sometimes / a little boring. それに、**research** は時々ちょっと堅苦しく聞こえる。

so if you're going to read up on something, だから **read up on ～** だと、

that kind of sounds like / you're interested in learning more about it too. 「自分も興味があってもっと知りたい」という感じも出る。

now I need to read up on / quantum physics 今度のテストのために、/ 量子物理学を勉強しないと。

for my upcoming test. 近々ある試験のために。

that doesn't sound like / as much fun, それはあまり楽しそうじゃないけど、

but you definitely need to read up on it しっかり勉強しないといけない。

if you need to study for something. 試験勉強が必要ならね。

**イメージ

read**→ ただ読む

**read up on**→ 読んで知識を増やす、勉強する、下調べする

例えば、

- *I read an article about Japan.*

  - 日本についての記事を読んだ。

- *I read up on Japan before my trip.*

  - 旅行前に日本についてかなり調べた。

後者は、

本や記事を何本も読んで知識を仕入れた

というニュアンスになります。

**よく使う例**

- *I need to read up on investing.*

  - 投資について勉強しないと。

- *I'm reading up on mountain climbing.*

  - 登山についていろいろ調べている。

- *You should read up on the company before the interview.*

  - 面接前にその会社について調べておいた方がいい。

**read up on = 「興味や必要性があって、あるテーマについて知識を仕入れるために読む」**

というイメージです。

to keep up with your studies**勉強についていく、学習のペースを維持する**

if you keep up with something, もし **keep up with ～** できているなら、

then you are maintaining the pace / of your studies. 勉強の進度についていけている、ということ。

the teacher is showing you / new information 先生は新しい内容を教えていて、

and you are learning it / at the same speed. あなたもそのペースで学んでいる。

keep up with the lecture, 講義についていきたいし、

or

oh, the original verb is keep up, right? もともとの句動詞は **keep up** なんだよね。

hey, keep up! 「遅れるな！」「ついてこい！」

you have to keep up. ちゃんとついていかなきゃ。

but then if you want to connect it / to an activity or an idea, でも活動や対象を後ろに置く時は、

you need to connect it / with the word "with".**with** を付ける必要がある。

keep up with my homework 宿題についていく

keep up with my classmates クラスメートについていく

right? そういうこと。

**イメージ

keep up**→ 遅れずについていく

**keep up with ～**→ ～と同じペースを維持する

例えば、
