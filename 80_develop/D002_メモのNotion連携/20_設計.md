- `.claude/skills/memo-notion/SKILL.md`：手順と決まりごと
- `.claude/skills/memo-notion/memo_notion.py`：決まった処理を受け持つ（Notion には触らない）
  - `plan [--limit N]`：対応表と `10_memo/` を比べ、追加・更新の一覧を出す
  - `body <メモID>`：frontmatter を除いた本文を出す
  - `record <メモID> <ページID>`：対応表に記録する（modified は `10_memo/` のファイルから読む）

## 3. データ
### 3.1 対応表 `notion_sync.json`（english の直下。git で管理）
```json
{
  "20260809-2": {
    "page_id": "（Notion のページ ID）",
    "modified": "2026-08-09T19:17+09:00",
    "sha256": "（送ったときのファイル全体のハッシュ）",
    "synced_at": "2026-10-24T08:00+09:00"
  }
}
```
- キーはメモ ID（`10_memo/` のファイルの `id`）。
- 判定：対応表にない → 追加。ファイルのハッシュが対応表の `sha256` と違う → 更新。それ以外 → 対象外。
- `modified` ではなくハッシュで比べる理由：メモアプリでチャンネルを移すと、`channel` は変わるが `modified` が変わるとは限らない（推測）ため。`modified` は記録として残す。

### 3.2 Notion の DB「Video learning」
| 欄 | 種類 | 中身 |
|---|---|---|
| タイトル | タイトル | メモの `title` |
| メモID | テキスト | メモの `id`（例：20260809-2） |
| チャンネル | 選択 | メモの `channel`（例：みさもさ、Video learning） |
| 作成日 | 日付 | メモの `created` |
| 更新日 | 日付 | メモの `modified` |
- 本文：メモの本文（frontmatter を除いた Markdown）。
- 置き場所：Wordbook と同じ階層（R008）。作れなければ I004 で相談する。

## 4. 処理の流れ（`/memo-notion`）
1. `memo_notion.py plan` で追加・更新の一覧を出す。0件なら伝えて終わる。
2. 一覧（ID と名前、追加か更新か）を見せ、送ってよいか聞く。件数が多いときは `--limit` で区切る。
3. 許可が出たら、1件ずつ：
   - 追加：DB にページを作る（欄と本文）→ `record` で対応表に記録する。
   - 更新：対応表のページ ID のページの欄と本文を置き換える → `record` で記録する。
   - 失敗：記録せずに次へ進み、最後に失敗した一覧を見せる。
4. `git diff -- notion_sync.json` を見せてからコミットする。push はしない。

## 5. セキュリティ・個人情報
- 外に送るもの：`10_memo/` のメモの中身（タイトル・チャンネル・日付・本文）。送り先はマメさんの Notion だけ。
- 鍵（トークン）：新しく持たない。今の Notion の接続を使う。
- 送る前に、チャットで一覧を見せて許可をもらう（R006）。Notion のツールの許可のダイアログとは別に行う。
- 対応表には Notion のページ ID だけを持つ。メモの中身は入れない。
