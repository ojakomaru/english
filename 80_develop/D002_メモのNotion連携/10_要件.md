## 2. 前提
- `/memo-import` で `10_memo/` が最新になっている。`/memo-notion` は `10_memo/` だけを読み、メモアプリには触らない。
- `10_memo/` の各ファイルの frontmatter に `id`・`title`・`channel`・`created`・`modified` がある（`memo_import.py` が書く）。
- この Mac の Claude Code から、マメさんの Notion にツールでつながっている（2026-10-24 に読み取りで確認）。

## 3. 制約
- Notion への書き込みは、今の Notion の接続（Claude Code のツール）で行う。API トークンは新しく持たない（50_決定記録 2026-10-24）。
- `10_memo/` のファイルは編集しない（取り込みで上書きされるため）。対応表は別のファイルに持つ。
- 確認なしで外部に送信しない（CLAUDE.md）。

## 4. 例外・異常時
- **対象が0件**：その旨を伝えて終わる。Notion には触らない。
- **途中で失敗**：書き込めたものだけ対応表に記録する。失敗したものは次の実行でまた対象になる。
- **重複**：対応表にページがあるメモは、新しいページを作らず、そのページを直す。
- **対応表にあるが Notion でページが消されていた**：書き込みに失敗するので、作り直すかをマメさんに聞く（勝手に作り直さない）。
- **チャンネルの移動**：メモアプリでフォルダを移すと `channel` が変わる。チャンネルの欄だけが変わる更新として扱う。
- **ロック付きメモ・画像・添付**：`10_memo/` にある内容（「本文は取り込めませんでした」や `[画像]` の目印）をそのまま写す。
- **長いメモ**：Notion の上限に当たるなら分けて書く（I003）。

## 5. 矛盾・ずれ
- CLAUDE.md（english）の「新しく覚えた単語・表現は vocab.md の表に追加する」は、R009（正本は Notion）と食い違う。I005 で CLAUDE.md を書き換えて解消する。

## 6. リスク
- **Notion で本文を直すと、次の更新で消える。** 本文はまるごと置き換えるため。Notion の本文は直接編集しない決まりにする（`10_memo/` と同じ扱い）。
- **ツールを「常に許可」にしていると、送信のダイアログが出ない。** チャットでの一覧の確認（R006）は、ダイアログとは別に必ず行う。
- **初回の148件は書き込みの回数が多い**ので、時間がかかる（推測）。分けて実行する（R007）。
