# D002_メモのNotion連携：実装計画

> **AI（実装する人）へ**：superpowers:subagent-driven-development または superpowers:executing-plans で、タスクを1つずつ進める。手順はチェックボックス（`- [ ]`）で進み具合を付ける。

**ゴール**：`10_memo/` の差分（追加・更新）を、Notion の DB「Video learning」に写すスキル `/memo-notion` を作り、初回の148件を移す。

**構成**：差分の判定・本文の取り出し・対応表の記録は、Python のスクリプト `memo_notion.py` が受け持つ（Notion には触らない）。Notion への書き込みは、スキルの手順に沿って Claude が今の Notion の接続（ツール）で行う。

**使うもの**：Python 3 の標準ライブラリだけ（テストは `unittest`）。Notion の接続（`notion-create-database`・`notion-create-pages`・`notion-update-page`・`notion-fetch`）。

**設計書**：[20_設計.md](20_設計.md)、[10_要件.md](10_要件.md)。実装する人は両方を読む。

## 全体の決まり
- 返答・文書・コミットメッセージは日本語。コミットの前に `git diff` を見せる。push はしない（ClaudeProjects の CLAUDE.md）。
- Notion に書き込む前に、何を書くかを見せてマメさんの許可をもらう（R006）。DB の作成（Task 2）も同じ。
- `10_memo/` のファイルは編集しない。
- Notion のページは削除しない（R004）。
- 対応表のファイルは english 直下の `notion_sync.json`。キーはメモ ID（例：`20260809-2`）。
- DB 名は「Video learning」。欄は タイトル／メモID／チャンネル／作成日／更新日（20_設計 3.2）。
- スクリプトは `python3 -I .claude/skills/memo-notion/memo_notion.py ...` で、english フォルダから実行する。

## 設計からの変更（この計画で提案。Task 1 で設計書も直す）
- **更新の判定に、ファイルの中身のハッシュを足す。** メモアプリでチャンネル（フォルダ）を移したとき、`memo_import.py` はファイルを移して `channel` を書き換えるが、`modified` が変わるとは限らない（推測）。`modified` だけで比べると、チャンネルの移動を見落とす。そこで対応表に `sha256`（ファイル全体のハッシュ）も持ち、「ハッシュが違えば更新」とする。`modified` は記録として残す。

## 気をつける入力（テストで押さえる）
1. **frontmatter に `id` がないファイル**（`10_memo/tmp/` など、取り込み以外で置かれたもの）→ 飛ばして警告を出す。止まらない。
2. **同じ `id` のファイルが2つある** → 両方を警告に出し、その ID は対象にしない（どちらを送るか決められないため）。
3. **対応表にあるが `10_memo/` にない ID** → 何もしない（削除しない。R004）。
4. **中身が同じ（ハッシュが同じ）** → 対象にしない。`modified` だけ新しくても、中身が同じなら送らない。
5. **`record` に `10_memo/` にない ID を渡す** → 何も書かずにエラーで終わる（終了コード 1）。

**受け渡し**
- 使うもの：`.claude/skills/memo-import/memo_import.py` の `read_front(path: Path) -> dict`（`sys.path` に memo-import のフォルダを足して import する。`-I` でも明示的に足したパスは使える）
- 作るもの（Task 3 のスキルが CLI として使う）：
  - `Memo`（dataclass）：`id: str, title: str, channel: str, created: str, modified: str, path: Path, sha256: str`
  - `load_memos(memo_dir: Path) -> tuple[dict[str, Memo], list[str]]`：ID → Memo と、警告の一覧
  - `load_state(path: Path) -> dict` ／ `save_state(path: Path, state: dict) -> None`（`ensure_ascii=False`、`indent=2`、キーで並べ、最後に改行。ファイルがなければ空の dict）
  - `plan(memos: dict[str, Memo], state: dict, limit: int | None = None) -> list[tuple[str, Memo]]`：`("add" | "update", Memo)` を `created` の古い順に。`limit` で先頭から区切る
  - `body(memo: Memo) -> str`：frontmatter を除いた本文
  - `record(state: dict, memo: Memo, page_id: str, now: str) -> dict`：`{"page_id", "modified", "sha256", "synced_at"}` を入れた新しい state を返す
  - CLI：
    - `plan [--limit N] [--json]`：人が読む一覧（`+ ID タイトル（チャンネル）`／`~ ...`、最後に件数と警告）。`--json` のときは `[{"kind","id","title","channel","created","modified","page_id"}]`
    - `body <ID>`：本文を標準出力に出す
    - `record <ID> <PAGE_ID>`：対応表に書く。`synced_at` は今の日時（JST、分まで）
    - 共通：`--memo-dir 10_memo`、`--state notion_sync.json`

  - `test_changed_content_is_update`：`record` 後に本文を変える → `("update", memo)`、`page_id` は対応表の値（V003）
