# /memo-import

Apple メモの学習メモを memo/ に取り込む。メモアプリが元データで、memo/ はその写し。

## 手順

1. 対象を確認する（書き込まない）。引数でフォルダ名が渡されたら `--folder "<フォルダ名>"` を付ける。
   ```bash
   python3 -I .claude/skills/memo-import/memo_import.py --dry-run
   ```
   - 「基準日時」は memo/ のファイルの `modified` の最大値（＝前回の取り込み）。
   - 追加・更新が 0 件なら、そう伝えて終わる。
2. 追加（`+`）・更新（`~`）の一覧を ID と名前のセットでユーザーに見せる。
3. `--dry-run` を外して実行する。
4. `git add memo` → `git diff --cached --stat` と、更新されたファイルは `git diff --cached -- <ファイル>` を見せてからコミットする。push はしない。

## 決まりごと

- ファイル名は `YYYYMMDD_タイトル.md`（作成日が ID）。同じ日に既にファイルがあれば `YYYYMMDD-N_` で既存の最大値＋1。
- 一度付いた ID は変えない。メモのタイトルが変わっても、既存ファイル（`apple_note_id` で対応付け）のファイル名はそのままで中身だけ更新する。
- メモアプリで削除したメモのファイルは消さない。
- memo/ のファイルを直接編集しない（次の取り込みで上書きされる）。気づきや訳の添削は log/ に書く。
- 画像・添付は `[画像]` `[添付]` の目印だけ残る。ロック付きメモは本文を取り込めない。
- 全件を取り込み直すときは `--all`、日時を指定するときは `--since 2026-10-01T00:00+09:00`。
- 初回はメモアプリの操作許可ダイアログが出るので、ユーザーに「許可」を押してもらう。
